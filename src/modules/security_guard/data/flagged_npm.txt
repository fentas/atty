# Flagged npm packages — atty's V1 Tier-1 fast-path bad-list.
#
# Single source of truth: this file is `include_str!`-loaded by
# atty-guard's classifier (Rust) AND `@embedFile`'d by atty's
# in-proc security_guard module (Zig). Editing here updates both
# sides on the next compile.
#
# Format: one package name per line. Lines starting with `#` are
# comments; blank lines are skipped. Use the BARE package name
# (no version, no scope-bracketing) — matching strips `@version`
# suffixes before comparison and the regex pattern is anchored
# at the `install` verb's argument boundary.
#
# Adding a new incident:
#   1. Open a PR adding the package(s) under a new dated heading.
#   2. Include a one-line citation to the disclosure or IOC source.
#   3. Subagent-review pings the maintainer; the test suite has
#      a sentinel test that asserts the seed entries below stay
#      matched (so no one accidentally removes one in a regex
#      tweak).
#
# Coverage philosophy: this list is the FAST PATH — the V1 user
# gets warned today. The comprehensive answer is the V2-F OSV /
# GitHub Advisory DB lookup which queries authoritative data at
# classify time. Keep this list FOCUSED on high-profile,
# high-blast-radius incidents the user is likely to encounter.
